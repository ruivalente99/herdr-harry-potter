# Inspiration and credits

This project is a Wizarding World (Harry Potter) Herdr layout built using the same mod architecture as `herdr-doomsday-heroes` and `herdr-star-wars`, originally inspired by [Herdr Middle-earth](https://github.com/joaovitorwoliveira/herdr-middle-earth).

Herdr mod lineages (`agents`, `toast`, `workspace-status`, `spaces`, `tabs` version `0.1.16`) are recorded in each mod's `cloned_from` metadata.
